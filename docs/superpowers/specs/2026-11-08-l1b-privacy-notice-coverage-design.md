La entrega de código puede completarse y probarse con fixtures explícitos sin presentar esos fixtures como datos reales.

`site/privacy-notice.js:privacyNoticeContentHash(notice):Promise<string>` calcula SHA-256 de JSON UTF-8 canónico de todos los campos salvo content_hash. Orden recursivo lexicográfico de claves; coverage como conjunto sin duplicados ordenado; links ordenados por id único y hash de label/href exactos; sections/paragraphs/bullets conservan orden visible. No trim o normalización oculta tras validar. `validatePrivacyNotice(value:unknown):Promise<NoticeValidation>` rechaza campos extra, valores indefinidos, IDs duplicados, fechas/versión inválidas, controlador distinto del literal, más de 30 secciones, 100 párrafos por sección o 2000 caracteres por párrafo; enlaces solo https a destinos permitidos y anchors internos explícitos. La entrada puede omitir content_hash: el resultado value siempre lo incluye calculado. Compara content_hash si se aporta; el proceso de preparación de configuración escribe el hash calculado y los consumidores recomputan el mismo algoritmo asíncrono con await. No hash autorreferente, firma jurídica ni metadata de aprobación.

`server/privacy-notice.js:loadPublishedPrivacyNotice(env):Promise<PrivacyNoticeV1>` queda como **lector propuesto del módulo manual actual**, sin tabla, CMS, estado approved o endpoint de publicación. El nombre se conserva para consumidores ya planeados; published significa versión incluida en el despliegue, no aprobación legal comprobada por la app. Importa la configuración y espera validatePrivacyNotice; configuración inválida da error sanitizado `NOTICE_CONFIGURATION_INVALID`, sin exponer textos privados ni sustituirlos por promesas inventadas. Site importa la misma configuración/funciones; no nuevo backend para servir o editar copy. La validación de preparación/release informa campos concretos; no efectúa cambios remotos ni activa servicios.

`site/apply.js:renderPrivacy(root):Promise<void>` mantiene la página actual, consume el módulo compartido y escribe texto/listas mediante textContent/esc, con enlaces seguros. La navegación que lo llama debe esperar la promesa, conservar el tratamiento de carga/error y descartar respuestas de una pantalla abandonada. No nueva página, editor admin, estados draft/approved/published/withdrawn ni puntero de releases.
