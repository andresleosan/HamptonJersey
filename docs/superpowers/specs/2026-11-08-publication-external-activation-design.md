## PUB-14 · Search Console existente, no nuevo SEO

Código server/seo.js y rutas ya producen canonical, previews, JSON-LD, sitemap y robots con dominio oficial. Continuidad: revisar que fichas privadas/borradores/archivadas no se indexan y no hay PII en metadata; no reconstruir SEO ni afirmar indexación por enviar sitemap. Operador con titular Hampton verifica propiedad de Search Console mediante canal autorizado existente, envía sitemap canónico y registra recepción/problemas. No cambiar DNS, crear cuenta, enviar verificación ni usar una conexión de terceros desde esta sesión. Estado de Search Console es hecho externo; si acceso no disponible, conservar activation_pending. Publicación de una ficha válida no espera esta activación para verse en web.
