# EST-15 · Scoped calculation, local foundation

Base: `7485ff9a1fa8d22ef2bd5a2d758d3a64ac862b75`. This is a pure, disconnected calculation with synthetic tests, not completion, integration, publication or activation of EST-15.

`resolveScopedUnavailability` consumes a complete bounded array of declarations and an explicit as-of time. Every declaration is validated, including those outside the requested scope. Only an exact match on property, operation, advertiser and publication is considered; null is an exact value, not a wildcard. A dated human negative with a nonempty reason and evidence reference yields `blocked`. A newer or simultaneous visible/modified web observation marks review without removing the block; an old or late-arriving observation cannot reactivate it. Missing or failed web observations are not negatives. Conflicting simultaneous human decisions produce `review`. A later human positive produces `not_confirmed`, which is not permission to act. Inputs are declarations only: the function cannot establish their authenticity, completeness or authority. Neither `review` nor `not_confirmed` authorizes action.

Validation: first run failed because the new module was absent; after implementation, `node --test tests/server/est-15-scoped-unavailability.test.mjs tests/server/property-facts.test.mjs` passed 21 tests on synthetic data. No browser, D1, network, real source, personal data or notification was used. The full suite was not run in this scoped work.
